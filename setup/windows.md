# Установка на Windows

Понадобятся две программы: компилятор **gcc**, который превращает текст программы в исполняемый файл `.exe`, и редактор **Eclipse**, в котором удобно писать код. Начинаем с компилятора.

Если на каком-то шаге что-то не получается, не тратьте на это часы — напишите преподавателю, где именно остановились, и мы разберём это на уроке.

## Шаг 1. Папка для программ

Создайте папку `C:\dev` — в ней будут лежать все программы курса. В названии папок на пути к программам не должно быть русских букв и пробелов, иначе компилятор может их не найти.

## Шаг 2. Компилятор gcc

В Windows 10 и 11 есть встроенный магазин программ для командной строки — winget. Он сам скачивает программу с официального сайта, проверяет её и настраивает. Компилятор ставится одной командой.

1. Нажмите Win+R, введите `cmd` и нажмите Enter. Откроется чёрное окно.
2. Вставьте в него эту команду и нажмите Enter:

```
winget install --id BrechtSanders.WinLibs.POSIX.UCRT -e
```

3. Если winget спросит согласие с условиями (появится вопрос с `[Y] Yes`), введите `Y` и нажмите Enter. Дальше просто ждите: скачивается большой архив, это займёт несколько минут. В конце появится слово `Successfully installed`.
4. Закройте чёрное окно и откройте новое (снова Win+R, `cmd`, Enter). Наберите:

```
gcc --version
```

Если появилась строка, которая начинается с `gcc (MinGW-W64 ...)`, компилятор работает. Если написано, что `gcc` не является командой, проверьте, что вы открыли именно новое окно — старые окна о компиляторе ещё не знают.

Если на шаге 2 Windows отвечает, что `winget` не является командой, напишите преподавателю — он даст другой способ установки.

## Шаг 3. Первая программа без Eclipse

1. Откройте Блокнот и вставьте программу:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, drone!\n");
    return 0;
}
```

2. Сохраните её как `C:\dev\hello.c`. В окне сохранения выберите «Тип файла: Все файлы», иначе Блокнот допишет к имени `.txt`.
3. В командной строке выполните по очереди:

```
cd C:\dev
gcc -std=c11 -Wall -Wextra -pedantic -o hello.exe hello.c
hello.exe
```

На экране должно появиться `Hello, drone!`. Длинную команду `gcc ...` запоминать не нужно — она всегда одна и та же, просто сохраните её себе.

## Шаг 4. Eclipse

1. Откройте https://www.eclipse.org/downloads/packages/ и найдите на странице блок **Eclipse IDE for C/C++ Developers**. Справа от него есть ссылки для разных систем — нажмите **Windows x86_64**.
2. Откроется страница с кнопкой **Download**. Нажмите её, скачается архив `.zip`.
3. Откройте архив. Внутри одна папка — `eclipse`. Перетащите её в `C:\dev`, чтобы получилась папка `C:\dev\eclipse`.
4. Зайдите в неё и запустите `eclipse.exe`. Eclipse спросит, где хранить проекты (workspace) — укажите папку `C:\dev\eclipse-workspace`.

Чтобы создать в Eclipse новую программу:

1. Выберите **File > New > C/C++ Project**, затем **C Managed Build** и Next.
2. Назовите проект `hello`. Слева выберите **Hello World ANSI C Project**, справа — **MinGW GCC**. Нажмите Finish.
3. В дереве слева откройте файл `src/hello.c` и замените его содержимое нашей программой.
4. **Ctrl+B** собирает программу, **Ctrl+F11** запускает. Ответ программы появляется внизу, во вкладке **Console**. Если программа ждёт число, щёлкните в Console и наберите его там.

Если в списке справа не оказалось пункта **MinGW GCC**, значит, Eclipse не нашёл компилятор. Закройте Eclipse, проверьте команду `gcc --version` в новом окне командной строки (шаг 2) и запустите Eclipse снова.

Предупреждения компилятора и кодировку в Eclipse настроим вместе на уроке.

## Два правила

- В программах используем только английские буквы — и в коде, и в тексте, который программа печатает. Русские буквы в чёрном окне Windows превращаются в нечитаемые символы.
- Если антивирус ругается на ваш `hello.exe`, это ложная тревога: маленькие только что собранные программы кажутся ему подозрительными. Добавьте папку `C:\dev` в исключения антивируса.
