# Первые уроки без установки: onlinegdb.com

Пока компилятор ещё не установлен на компьютере, программы можно писать и запускать прямо в браузере — на сайте onlinegdb.com.

## Как запустить программу

1. Откройте страницу https://www.onlinegdb.com/online_c_compiler
2. В правом верхнем углу выберите язык **C** (именно C, а не C++).
3. Сотрите всё, что уже написано в большом окне, и вставьте туда свою программу.
4. Нажмите зелёную кнопку **Run**.
5. Внизу появится чёрное окно — в нём программа напечатает свой ответ.

Проверьте, что всё работает, на такой программе:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, drone!\n");
    return 0;
}
```

В чёрном окне должна появиться строка `Hello, drone!`.

## Если программа ждёт ввода

Когда программа просит ввести число, она останавливается и ничего не печатает — так и должно быть. Щёлкните мышкой в чёрное окно, наберите число и нажмите Enter.

## Чтобы код не потерялся

Пока вы на сайте, программа хранится только до закрытия вкладки. Используйте кнопку **Download**, сохраняйте работу после каждого урока.

## Если что-то пошло не так

- Появились красные строки со словом `error` — в программе опечатка. Сравните её с образцом: скобки, кавычки, точка с запятой в конце каждой команды.
- Программа никак не останавливается — нажмите **Stop** (эта кнопка появляется на месте Run, пока программа работает).
- Ошибки в заведомо правильном коде — проверьте, что выбран язык C, а не C++.
