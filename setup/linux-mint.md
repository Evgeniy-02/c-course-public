# Установка на Linux Mint

## Шаг 1. Компилятор

Откройте терминал (Ctrl+Alt+T) и выполните:

```
sudo apt update && sudo apt install build-essential git
```

Проверьте, что компилятор появился:

```
gcc --version
```

Если напечаталась строка с номером версии, всё готово.

## Шаг 2. Первая программа

1. Создайте папку для курса и откройте в ней новый файл:

```
mkdir -p ~/c-course && cd ~/c-course
xed hello.c
```

2. Вставьте программу и сохраните файл (Ctrl+S):

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, drone!\n");
    return 0;
}
```

3. Вернитесь в терминал и выполните:

```
gcc -std=c11 -Wall -Wextra -pedantic -o hello hello.c
./hello
```

На экране должно появиться `Hello, drone!`. Длинная команда `gcc ...` всегда одна и та же, запоминать её не нужно. Стрелка вверх в терминале повторяет предыдущую команду, так что обычный порядок работы такой: поправили код, сохранили, нажали стрелку вверх и Enter.

Запускать программу нужно с `./` в начале — просто `hello` не сработает. Если программа зациклилась, нажмите Ctrl+C.

## Шаг 3. Eclipse

1. Откройте https://www.eclipse.org/downloads/packages/
2. Скачайте **Eclipse IDE for C/C++ Developers** для Linux (файл `.tar.gz`).
3. Распакуйте архив в домашнюю папку и запустите Eclipse:

```
cd ~ && tar -xzf ~/Downloads/eclipse-cpp-*-linux-gtk-x86_64.tar.gz
~/eclipse/eclipse
```

4. Eclipse спросит, где хранить проекты, — оставьте предложенную папку.

Чтобы создать в Eclipse новую программу:

1. Выберите **File > New > C/C++ Project**, затем **C Managed Build** и Next.
2. Назовите проект `hello`. Слева выберите **Hello World ANSI C Project**, справа — **Linux GCC**. Нажмите Finish.
3. Откройте файл `src/hello.c` и замените его содержимое нашей программой.
4. **Ctrl+B** собирает программу, **Ctrl+F11** запускает. Ответ появляется внизу, во вкладке **Console**. Если программа ждёт число, щёлкните в Console и наберите его там.

Предупреждения компилятора в Eclipse настроим вместе на уроке.

## Если что-то пошло не так

- `gcc: command not found` — шаг 1 не выполнен, повторите его.
- `Permission denied` или `command not found` при запуске — забыли `./` перед именем программы.
- Много ошибок сразу — исправьте только первую и соберите программу снова, остальные часто исчезают сами.
