# Как сдавать домашнее задание через git

Git хранит файлы на сервере GitHub и запоминает, кто и что в них менял. У каждого ученика свой репозиторий, закрытый от посторонних: видите его только вы и преподаватель. Адрес репозитория даст преподаватель, он выглядит так: `github.com/c-course-school/<имя>`.

Внутри репозитория для каждого урока есть своя каталог:

```
lesson01/
lesson02/
lesson03/
lesson04/
lesson05/
```

Домашнее задание к уроку 4 кладётся в каталог `lesson04/`, и так далее.

Первые шесть шагов выполняются один раз, при настройке компьютера. Шаг 7 повторяется после каждого урока.

## 1. Регистрация на GitHub

1. Откройте https://github.com и нажмите Sign up.
2. Придумайте логин латиницей, укажите почту и пароль.
3. Сообщите логин преподавателю. Он откроет вам доступ к репозиторию, и на почту придёт приглашение.
4. Откройте письмо и нажмите Accept invitation.

## 2. Установка git

На Windows скачайте установщик с https://git-scm.com и установите его, ничего не меняя в настройках. Вместе с git на компьютере появится программа Git Bash.

На Linux Mint откройте терминал (Ctrl+Alt+T) и выполните:

```
sudo apt install git
```

## 3. Где вводить команды

Все команды из этой инструкции вводятся в окне для команд, а не в редакторе кода и не в браузере.

На Windows это программа Git Bash: откройте меню «Пуск», начните набирать `Git Bash` и нажмите Enter. Откроется чёрное окно, в котором строка заканчивается знаком `$`. Чёрное окно `cmd`, которое использовалось при установке компилятора, для git не подходит: в нём не работают некоторые команды ниже.

На Linux Mint это терминал: нажмите Ctrl+Alt+T.

Команду набирают или вставляют одной строкой и нажимают Enter. Скопировать текст из окна: выделите его мышью, затем на Windows нажмите правую кнопку мыши и выберите Copy, на Linux Mint нажмите Ctrl+Shift+C. Вставить текст в окно: на Windows правая кнопка мыши и Paste, на Linux Mint Ctrl+Shift+V.

Дальше команды одинаковы для обеих систем.

## 4. Ключ доступа

Пароль от сайта git не принимает. Вместо него компьютер и GitHub узнают друг друга по ключу. Ключ создаётся один раз.

1. Откройте окно для команд: на Windows программу Git Bash, на Linux Mint терминал (как описано в шаге 3). Введите в него команду, подставив почту, с которой регистрировались на GitHub:

```
ssh-keygen -t ed25519 -C "misha@example.com"
```

2. На все вопросы нажимайте Enter.
3. Напечатайте на экран открытую часть ключа:

```
cat ~/.ssh/id_ed25519.pub
```

4. Появится одна длинная строка, которая начинается с `ssh-ed25519`. Выделите её целиком и скопируйте.
5. Откройте https://github.com/settings/keys и нажмите New SSH key.
6. В поле Title напишите, что это за компьютер, например `home laptop`. В большое поле вставьте скопированную строку. Нажмите Add SSH key.
7. Проверьте, что ключ работает:

```
ssh -T git@github.com
```

Первый раз команда спросит, доверять ли серверу. Напишите `yes` и нажмите Enter. Если в ответ пришло `Hi <ваш логин>!`, всё готово.

## 5. Имя и почта

Каждая отправка на сервер подписывается именем и почтой, поэтому их нужно один раз сообщить git. В том же окне для команд введите две команды, подставив своё имя латиницей и ту же почту:

```
git config --global user.name "Misha Ivanov"
git config --global user.email "misha@example.com"
```

В ответ ничего не напечатается, так и должно быть.

## 6. Скачивание репозитория

1. В окне для команд (Git Bash или терминал) перейдите в каталог для программ, который создавали при установке компилятора. На Windows:

```
cd C:/dev
```

На Linux Mint:

```
cd ~/c-course
```

2. Скачайте свой репозиторий, подставив адрес, который дал преподаватель:

```
git clone git@github.com:c-course-school/<имя>.git
```

3. В каталоге для программ появится каталог с вашим именем, а внутри неё каталоги уроков. Это и есть ваш репозиторий на вашем компьютере.

## 7. Отправка домашнего задания

1. Сохраните файл с программой в каталог нужного урока. На Windows это, например, `C:\dev\<имя>\lesson04`, на Linux Mint `~/c-course/<имя>/lesson04`. Файл можно сохранить туда прямо из редактора или скопировать через проводник.
2. Откройте окно для команд: на Windows Git Bash, на Linux Mint терминал. Перейдите в каталог репозитория. На Windows:

```
cd C:/dev/<имя>
```

На Linux Mint:

```
cd ~/c-course/<имя>
```

3. Выполните три команды:

```
git add .
git commit -m "lesson 04 homework"
git push
```

Первая команда собирает изменённые файлы, вторая записывает их с подписью, третья отправляет на сервер. В подписи после `-m` коротко и латиницей опишите, что сделано, например `lesson 04 homework` или `lesson 05 task 2`.

4. Откройте свой репозиторий в браузере и убедитесь, что файлы появились. Преподаватель посмотрит их и оставит замечания рядом с кодом.

В репозиторий не кладут собранные программы (`.exe`) и каталог `Debug`, только файлы `.c`.

## Если что-то пошло не так

| Сообщение | Что это значит и что делать |
|-----------|-----------------------------|
| `rejected` после `git push` | Сначала выполните `git pull`, потом снова `git push`. |
| `Please tell me who you are` | Пропущен шаг 5. |
| `Permission denied (publickey)` | Ключ не добавлен на GitHub или добавлен не в тот аккаунт. Повторите шаг 4. |
| `Repository not found` | Приглашение ещё не принято. Проверьте почту, шаг 1. |
| `not a git repository` | Вы не в каталоге репозитория. Перейдите в неё, как в шаге 7. |
| `CONFLICT` или что-то непонятное | Ничего не удаляйте. Скопируйте текст ошибки целиком и отправьте преподавателю. |
