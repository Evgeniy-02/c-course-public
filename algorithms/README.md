# Банк алгоритмов на C

Здесь собраны программы, которые вы уже писали на D, теперь на C. Одна программа — один файл. Все значения записаны прямо в программе (кроме [guess_number.c](guess_number.c), она ждёт ввода с клавиатуры), поэтому каждую программу можно сразу скомпилировать и запустить:

```
gcc -std=c11 -Wall -Wextra -pedantic -o name name.c && ./name
```

На Windows в командной строке вместо последней части пишут имя программы отдельной командой:

```
gcc -std=c11 -Wall -Wextra -pedantic -o name.exe name.c
name.exe
```

Вместо `name` подставьте имя файла без `.c`, например `palindrome`.

Для каждой программы без ввода с клавиатуры есть файл `expected_<имя>.txt` с точным ожидаемым выводом. Скрипт [check.sh](check.sh) компилирует все программы в каталог `build/`, запускает их и сравнивает вывод с ожидаемым. Любое предупреждение компилятора он считает ошибкой. Запускается он командой `bash check.sh` в терминале Linux или в Git Bash на Windows.
