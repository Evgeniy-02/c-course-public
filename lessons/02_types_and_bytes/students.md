# Урок 2. Типы и байты

## Три типа

| Тип | Что хранит | Пример | Печать | Ввод |
|-----|------------|--------|--------|------|
| `int` | целое число | `int cells = 4;` | `%d` | `scanf("%d", &cells);` |
| `double` | дробное число | `double voltage = 3.85;` | `%f`, `%.2f` | `scanf("%lf", &voltage);` |
| `char` | один символ | `char letter = 'S';` | `%c` | `scanf(" %c", &letter);` |

`%.2f` печатает два знака после точки — `3.85`, а `%.0f` выводит число без дробной части.

Символ — это тоже число: `'A'` равно `65`, `'B'` — `66`, а `'0'` — `48`.

`sizeof(int)` показывает, сколько байт занимает тип: `int` — 4 байта, `double` — 8, `char` — 1.

## Деление

| Выражение | Результат | Почему |
|-----------|-----------|--------|
| `7 / 2` | `3` | оба числа целые, дробная часть отбрасывается |
| `7 % 2` | `1` | остаток от деления |
| `7.0 / 2` | `3.5` | одно из чисел дробное, поэтому и результат дробный |
| `(double) 7 / 2` | `3.5` | `(double)` превращает 7 в 7.0 |

Ловушка: `double x = 7 / 2;` даст `3.0`, потому что деление выполнилось ещё в целых числах.

## Переполнение

В `int` помещаются числа примерно до двух миллиардов. Если прибавить единицу к `2147483647`, получится `-2147483648` — число «переворачивается». В прошивках такое переполнение оборачивается настоящей ошибкой.

## Шпаргалка

```c
int cells = 4;                       // целое
double voltage = 15.2;               // дробное
char letter = 'S';                   // символ

scanf("%lf", &voltage);              // ввод double
printf("%.2f V\n", voltage / cells); // печать с 2 знаками
int rest = 17 % 5;                   // 2
double half = (double) 7 / 2;        // 3.5
```
