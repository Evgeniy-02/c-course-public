# Урок 6. Массивы

## Объявление массива

Гироскоп выдаёт показания сотни раз в секунду, и создавать для каждого из них отдельную переменную невозможно. Для ряда однотипных значений есть массив:

```c
int altitudes[5] = {10, 12, 15, 15, 14};
int count = 5;

printf("%d\n", altitudes[0]);
altitudes[1] = 13;
```

Массив — это несколько переменных одного типа под одним именем. В квадратных скобках при объявлении стоит размер, а в фигурных — начальные значения. К отдельному элементу обращаются по индексу: `altitudes[1]` можно читать и можно присваивать, как обычную переменную.

## Индексы начинаются с нуля

В массиве из пяти элементов индексы идут от 0 до 4: первый элемент — `altitudes[0]`, последний — `altitudes[count - 1]`. Элемента `altitudes[5]` не существует, и компилятор об этом не предупредит: программа прочитает память за пределами массива, и результат будет непредсказуемым. Поэтому цикл по массиву всегда выглядит так:

```c
for (int i = 0; i < count; i++) {
    printf("%d ", altitudes[i]);
}
```

Условие `i < count`, а не `i <= count`, и это самая частая ошибка с массивами.

## Массив передаётся в функцию вместе с длиной

```c
int count_above(const int values[], int count, int limit)
{
    int above = 0;
    for (int i = 0; i < count; i++) {
        if (values[i] > limit) {
            above++;
        }
    }
    return above;
}

int high = count_above(altitudes, count, 12);
```

Массив сам не знает свою длину, поэтому рядом с ним всегда передаётся `int count`. При вызове пишется только имя массива, без скобок. Слово `const` перед типом обещает, что функция массив не изменит. Без `const` функция может менять элементы, и изменения видны снаружи — в отличие от обычных параметров, массив в функцию не копируется.

## Задание 3. Пузырьковая сортировка

Заготовка: [code/06_bubble_sort_start.c](code/06_bubble_sort_start.c).

Функция `bubble_sort` сортирует массив по возрастанию: за один проход сравниваются все пары соседей, и если левый больше правого, они меняются местами. После каждого прохода самый большой из оставшихся элементов оказывается на своём месте в конце, поэтому следующий проход на один элемент короче. Программа печатает массив после каждого прохода.

```
Original: 9 5 7 1 8 2
Pass 1: 5 7 1 8 2 9
Pass 2: 5 1 7 2 8 9
Pass 3: 1 5 2 7 8 9
Pass 4: 1 2 5 7 8 9
Pass 5: 1 2 5 7 8 9
Sorted: 1 2 5 7 8 9
```

## Шпаргалка

```c
int values[4] = {5, 3, 8, 1};        // массив из 4 int
int count = 4;                       // длину храним отдельно
values[0] = 7;                       // первый элемент
values[count - 1] = 9;               // последний элемент
for (int i = 0; i < count; i++) { }  // обход: i < count, не <=
int sum_of(const int values[], int count) { ... }  // const: не меняет
void fill(int values[], int count) { ... }         // без const: меняет
sum_of(values, count);               // при вызове только имя
```
