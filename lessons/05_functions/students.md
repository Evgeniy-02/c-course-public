# Урок 5. Функции

## Определение функции

```c
int add(int a, int b)
{
    int sum = a + b;
    return sum;
}
```

Функция — это часть программы, у которой есть имя и которую можно вызывать сколько угодно раз. Перед именем стоит тип результата (`int`), в скобках перечислены параметры с типами, а `return` возвращает результат и сразу завершает функцию. `main` — тоже функция, только вызывает её не программист, а система при запуске программы.

## Вызов функции

Чтобы функция сработала, её вызывают по имени и передают в скобках значения — аргументы:

```c
int total = add(2, 3);
printf("%d\n", add(total, 10));
```

При вызове, значения копируются в параметры: `a` получает 2, `b` получает 3. Результат можно положить в переменную или сразу передать в `printf`.

Функция может возвращать `bool` — тогда её имя звучит как вопрос, а вызов удобно ставить прямо в `if`:

```c
bool is_low(double cell_voltage)
{
    return cell_voltage < 3.5;
}

if (is_low(3.42)) {
    printf("Land soon\n");
}
```

## Переменные внутри функции — свои

```c
void try_to_double(int n)
{
    n = n * 2;
}
```

Функция работает с копией: если внутри изменить `n`, переменная, которую передали при вызове, останется прежней. Слово `void` вместо типа результата означает, что функция ничего не возвращает, а `void` в скобках — что параметров нет: `void print_line(void)`.

## Функции пишутся выше main

Компилятор читает файл сверху вниз, поэтому функция должна быть описана раньше того места, где её вызвали. Проще всего писать все функции выше `main`. Если функцию хочется оставить внизу, наверху файла пишут её прототип — заголовок с точкой с запятой, например `int add(int a, int b);`. В этом курсе мы обходимся без прототипов и просто держим функции выше `main`.

## Задание 3. НОД и НОК


## Шпаргалка

```c
int add(int a, int b)            // тип результата, имя, параметры
{
    return a + b;                // вернуть результат и выйти
}
bool is_low(double v) { return v < 3.5; }  // функция-вопрос
void print_line(void) { ... }    // ничего не возвращает, без параметров
int total = add(2, 3);           // вызов: значения копируются в a и b
```
