# Урок 8. Биты

## Число — это набор битов

```c
unsigned char status = 12;
```

Тип `unsigned char` занимает один байт — восемь битов — и хранит целое число от 0 до 255. Число 12 в этом байте выглядит как `00001100`: биты нумеруются справа налево, начиная с нуля, а бит с номером n соответствует числу 2 в степени n. Веса битов слева направо — 128, 64, 32, 16, 8, 4, 2, 1, поэтому 12 это 8 + 4. В прошивках тот же тип обычно пишут как `uint8_t` из `stdint.h`, но смысл точно такой же.

## Операции с битами

Четыре операции для `a = 12` и `b = 10`:

```
a      = 00001100  (12)
b      = 00001010  (10)
a & b  = 00001000  (8)   и: единица только там, где единица в обоих
a | b  = 00001110  (14)  или: единица там, где единица хотя бы в одном
a << 1 = 00011000  (24)  сдвиг влево на один бит, число удваивается
a >> 1 = 00000110  (6)   сдвиг вправо на один бит, число делится на 2
```

Сдвиг на n битов — это умножение или деление на 2 в степени n: `1 << 9` даёт 512. Один знак `&` — это операция над битами, а два знака `&&` — логическое «и» из урока 3, не путайте их.

## Шестнадцатеричная запись

Восемь нулей и единиц писать долго, поэтому байты принято записывать короче — двумя шестнадцатеричными цифрами:

```c
unsigned char mask = 0x0F;
printf("0x%02X\n", mask);
```

Приставка `0x` означает шестнадцатеричную систему: цифры в ней идут от `0` до `9`, а дальше буквы от `A` до `F` обозначают числа от 10 до 15. Одна такая цифра — это ровно четыре бита, поэтому `0x0F` это `00001111` (15), а `0xA5` это `10100101` (165). Формат `%02X` печатает число в том же виде — две шестнадцатеричные цифры заглавными буквами.

## Один бит из байта

```c
unsigned char status = 0;
status = status | (1 << 2);
if ((status & (1 << 2)) != 0) {
    printf("bit 2 is on\n");
}
```

`1 << 2` — это байт, в котором стоит только бит номер 2. Операция `|` с ним включает этот бит в `status`, а `&` с ним проверяет, включён ли он. Чтобы бит выключить, нужна ещё одна операция — `~` переворачивает все биты, так что `~(1 << 2)` это байт, где стоят все биты, кроме второго, и `status & ~(1 << 2)` выключает именно его. Так в прошивке в одном байте хранят сразу восемь флагов «да или нет».

## Шпаргалка

```c
unsigned char status = 12;         // один байт, 0..255, 00001100
status = status | (1 << 5);        // включить бит 5
status = status & ~(1 << 5);       // выключить бит 5
int bit5 = (status >> 5) & 1;      // прочитать бит 5: 0 или 1
int doubled = status << 1;         // умножить на 2
printf("0x%02X\n", status);        // напечатать как hex: 0x0C
```
