# Урок 4. Циклы

## Цикл while

До сих пор каждая строка программы выполнялась один раз. Цикл повторяет часть программы много раз, и `while` — самый простой из циклов: «пока условие верно, выполняй тело». Обратный отсчёт перед взлётом:

```c
int countdown = 3;
while (countdown > 0) {
    printf("%d...\n", countdown);
    countdown = countdown - 1;
}
printf("Takeoff!\n");
```

Сначала проверяется условие `countdown > 0`; если оно верно, выполняется тело в фигурных скобках, и всё повторяется. Когда `countdown` дойдёт до нуля, условие станет ложным, цикл закончится, и программа перейдёт к строке `Takeoff!`. Если забыть уменьшить `countdown`, условие никогда не станет ложным, и цикл станет бесконечным. Остановить такую программу можно клавишами Ctrl+C в терминале или кнопкой Stop на onlinegdb.

## Цикл for

Чаще всего цикл нужен, чтобы пройти по числам от одного до другого. Для этого есть `for`, в котором счётчик, условие и шаг собраны в одной строке:

```c
for (int i = 1; i <= 5; i++) {
    printf("i = %d\n", i);
}
```

В скобках три части через точку с запятой: начало `int i = 1` выполняется один раз перед циклом, условие `i <= 5` проверяется перед каждым повтором, а шаг `i++` выполняется после каждого повтора. Этот цикл напечатает числа от 1 до 5. Когда число повторов известно заранее, берут `for`; когда неизвестно, как в отсчёте по условию, — `while`.

## Сокращения

Запись `i = i + 1` встречается так часто, что для неё придумали короткие формы. Они ничего нового не делают, просто короче:

| Запись | Смысл |
|--------|-------|
| `i++` | `i = i + 1` |
| `i--` | `i = i - 1` |
| `sum += x` | `sum = sum + x` |
| `acc *= i` | `acc = acc * i` |
| `rest /= 10` | `rest = rest / 10` |

## Аккумулятор

Чтобы сложить много чисел, заводят переменную, в которую на каждом шаге цикла добавляют очередное число. Такую переменную называют аккумулятором: она накапливает результат. Для суммы, её начальное значение равно 0, для произведения — 1 (иначе всё умножится на ноль).

```c
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
```

## Досрочный выход из цикла

Иногда нужно выйти из цикла раньше, чем условие станет ложным, например, число найдено, и искать дальше незачем. Для этого есть команда `break`: она немедленно прерывает цикл, и программа продолжается со строки после него.

## Случайное число

```c
#include <stdlib.h>
#include <time.h>

srand(time(NULL));
int secret = rand() % 100 + 1;
```

Функция `rand()` выдаёт случайное целое число, а остаток от деления на 100 плюс единица помещает его в диапазон от 1 до 100. Перед первым вызовом `rand()` один раз выполняют `srand(time(NULL))` — так генератору задаётся начальное значение по текущему времени; без этого при каждом запуске программа будет выдавать одно и то же число. Функции `rand` и `srand` объявлены в `stdlib.h`, а `time` — в `time.h`.

## Шпаргалка

```c
while (voltage > 3.3) { ... }          // повторять, пока условие верно
for (int i = 1; i <= n; i++) { ... }   // счётчик от 1 до n
sum += i;  acc *= i;  i++;             // сокращения
break;                                 // выход из цикла
srand(time(NULL)); rand() % 100 + 1;   // случайное 1..100
```
