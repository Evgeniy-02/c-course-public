# Урок 10. Структуры

## Структура: несколько переменных под одним именем

Состояние мотора описывают сразу несколько чисел: его номер, обороты, крутится ли он. Держать их в отдельных переменных неудобно, особенно когда моторов четыре. Структура собирает несколько полей разных типов в один новый тип.

```c
typedef struct {
    int number;
    int rpm;
    bool spinning;
} Motor;

Motor left_front = { 1, 0, false };
left_front.rpm = 8000;
printf("motor %d: %d rpm\n", left_front.number, left_front.rpm);
```

Слово `typedef` даёт структуре имя `Motor`, и дальше оно используется как обычный тип — как `int` или `double`. Значения в фигурных скобках идут в порядке объявления полей, а к каждому полю обращаются через точку.

## Структура в функции: копия

Структуру можно передать в функцию как обычный параметр. Функция получит копию — как и с числами, изменения внутри функции на оригинал не влияют. То же самое при присваивании: `Motor backup = left_front;` создаёт независимую копию.

```c
void print_motor(Motor motor)
{
    printf("motor %d: %d rpm\n", motor.number, motor.rpm);
}

print_motor(left_front);
```

## Указатель на структуру: стрелка

Чтобы функция изменила саму структуру, ей передают адрес, точно так же, как на прошлом уроке. Поле через указатель пишется стрелкой `->` вместо точки.

```c
void spin_up(Motor *motor, int rpm)
{
    motor->rpm = rpm;
    motor->spinning = true;
}

spin_up(&left_front, 12000);
```

Запись `motor->rpm` означает «поле `rpm` структуры, на которую указывает `motor`». Правило то же: в вызове `&`, в функции — стрелка.

## Шпаргалка

```c
typedef struct { int id; double reading; } Sensor;  // новый тип
Sensor gyro = { 1, 0.5 };          // поля в порядке объявления
gyro.reading = 0.7;                // доступ через точку
Sensor saved = gyro;               // копия, оригинал не меняется
void zero(Sensor *sensor)          // адрес, чтобы менять оригинал
{ sensor->reading = 0.0; }         // через указатель стрелка
zero(&gyro);                       // вызов с &
```
