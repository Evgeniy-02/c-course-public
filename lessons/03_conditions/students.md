# Урок 3. Условия

## Сравнения

Результат сравнения — `1` (истина) или `0` (ложь).

| Пример                               | Смысл                                              |
| ------------------------------------ | -------------------------------------------------- |
| `x == 5`                             | равно (два знака!)                                 |
| `x != 5`                             | не равно                                           |
| `x < 5`, `x <= 5`, `x > 5`, `x >= 5` | меньше, меньше или равно, больше, больше или равно |
| `a && b`                             | логическое и                                       |
| <code>a &#124;&#124; b</code>        | логическое или                                     |
| `!a`                                 | логическое не                                      |

Один знак равно — это не сравнение, а присваивание: `x = 5` кладёт в `x` число 5.

Так проверяют, что число попадает в диапазон: `x >= 0 && x <= 100`.

## bool

```c
#include <stdbool.h>

bool too_high = altitude > 120;
bool too_fast = speed > 30;
```

Имя такой переменной звучит как вопрос, а значение у неё одно из двух — `true (1)` или `false (0)`.

## if / else

```c
if (too_high && too_fast) {
    printf("Slow down and descend\n");
} else if (too_high) {
    printf("Descend\n");
} else {
    printf("All good\n");
}
```

Условие пишется в круглых скобках, а фигурные скобки ставятся всегда, даже для одной строки.

## Ввод символа

```c
char arm_switch = 'n';
scanf(" %c", &arm_switch);
```

Пробел перед `%c` нужен, иначе программа прочитает Enter, оставшийся от предыдущего ввода.

## Домашнее задание

### Задача 1. Зоны газа

Программа получает газ в процентах и печатает, что происходит с дроном.

| Газ | Вывод |
|-----|-------|
| меньше 0 или больше 100 | `Invalid throttle` |
| 0..4 | `Idle: motors spinning slowly` |
| 5..49 | `Low: descending` |
| 50..79 | `Hover: holding altitude` |
| 80..100 | `Full: climbing fast` |

```
Throttle (0-100): 65
Hover: holding altitude
```

### Задача 2. Високосный год

```
Year: 2024
2024 is a leap year
```

```
Year: 1900
1900 is not a leap year
```
