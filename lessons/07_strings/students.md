# Урок 7. Строки

## Строка — это массив символов

```c
char name[16] = "drone";
```

В массиве из 16 ячеек лежат пять букв, а сразу за ними — невидимый символ `'\0'`, число ноль. По нему `printf("%s")` и другие функции понимают, где строка заканчивается, а остальные ячейки массива просто не используются. К буквам можно обращаться по индексу: `name[0]` — это `'d'`, `name[4]` — `'e'`, а `name[5]` — тот самый ноль.

## Ввод строки

Слово с клавиатуры читается тем же `scanf`, что и числа, только формат другой — `%s`, а перед ним ставится наибольшая длина:

```c
char command[32];
printf("Command: ");
scanf("%31s", command);
```

`%31s` читает одно слово — до пробела или конца строки — и кладёт в массив не больше 31 символа, чтобы осталось место для `'\0'`. Знак `&` здесь не нужен: имя массива — это уже адрес его начала.

## Сравнение и длина

Сравнивать строки через `x == y` нельзя: так сравнятся адреса массивов, а не буквы. Для строк есть готовые функции:

```c
#include <string.h>

if (strcmp(command, "arm") == 0) {
    printf("Arming\n");
}
int length = strlen(command);
```

Обе функции объявлены в `string.h`. `strcmp` возвращает 0, когда строки одинаковые, и другое число, когда они отличаются, — поэтому сравнение пишется именно как `strcmp(a, b) == 0`. `strlen` возвращает число символов до `'\0'`: для `"arm"` это 3.

## Шпаргалка

```c
#include <string.h>

char name[16] = "drone";              // 5 букв и '\0' в конце
char word[32];
scanf("%31s", word);                  // одно слово, без &
int length = strlen(word);            // символов до '\0'
if (strcmp(word, "arm") == 0) { ... } // строки одинаковые
char first = word[0];                 // символ по индексу
```
