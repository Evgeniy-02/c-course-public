# Урок 1. Первая программа на C

## Зачем C

Прошивки полётных контроллеров (Betaflight, INAV, ArduPilot), Arduino, ESP32,
STM32 написаны на C. Чтобы программировать дроны, нужно уметь читать и писать
на C.

## Из чего состоит программа

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, drone!\n");
    return 0;
}
```

| Строка | Что делает |
|--------|------------|
| `#include <stdio.h>` | подключает печать и ввод (как `import std.stdio;` в D) |
| `int main(void)` | отсюда начинается программа |
| `printf("...\n");` | печатает текст, `\n` переводит строку |
| `return 0;` | конец программы, 0 значит «всё хорошо» |

Каждая команда заканчивается точкой с запятой `;`.

## Как запустить

На onlinegdb.com: язык **C**, кнопка **Run**. Ввод набираем в чёрной консоли
внизу и нажимаем Enter.

В терминале:

```
gcc -std=c11 -Wall -Wextra -pedantic -o hello hello.c && ./hello
```

## Переменные и печать

```c
int capacity_mah = 1500;
printf("Capacity: %d mAh\n", capacity_mah);
```

`%d` это дырка под целое число. После запятой перечисляем, чем заполнить дырки:

```c
int a = 5;
int b = 9;
printf("%d + %d = %d\n", a, b, a + b);
```

Напечатает `5 + 9 = 14`.

## Ввод числа

```c
int voltage = 0;
printf("Voltage: ");
scanf("%d", &voltage);
```

В `scanf` перед переменной всегда `&`. В `printf` никогда.

## Было на D, стало на C

| D | C |
|---|---|
| `import std.stdio;` | `#include <stdio.h>` |
| `void main() { }` | `int main(void) { return 0; }` |
| `writeln("x = ", x);` | `printf("x = %d\n", x);` |
| `readf(" %d", &x);` | `scanf("%d", &x);` |
| `int c = a * b;` | `int c = a * b;` |

Заготовки к заданиям: папка `code/` рядом с этим конспектом.

## Задание 1. Время полёта

Батарея 1500 mAh, моторы тянут 30 A. Сколько минут полетаем?

Минуты = ёмкость · 60 / (ток · 1000).

```

Motor current (A): 30
Flight time: 3 minutes
```

## Шпаргалка

```c
#include <stdio.h>          // печать и ввод

int x = 0;                  // целая переменная
printf("x = %d\n", x);      // печать
scanf("%d", &x);            // ввод, не забыть &
```
