# Урок 1. Первая программа на C

## Зачем C

Прошивки полётных контроллеров (Betaflight, INAV, ArduPilot), а также программы для Arduino, ESP32 и STM32 написаны на языке C. Поэтому, чтобы программировать дроны, нужно уметь читать и писать код на C.

## Из чего состоит программа

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, drone!\n");
    return 0;
}
```

| Строка | Что делает |
|--------|------------|
| `#include <stdio.h>` | подключает печать и ввод (как `import std.stdio;` в D) |
| `int main(void)` | отсюда начинается программа |
| `printf("...\n");` | печатает текст, `\n` переводит строку |
| `return 0;` | конец программы, 0 значит «всё хорошо» |

Каждая команда заканчивается точкой с запятой — `;`.

## Как запустить

На сайте onlinegdb.com выберите язык **C** и нажмите кнопку **Run**. Если программа ждёт ввода, наберите значение в чёрной консоли внизу и нажмите Enter.

В терминале:

```
gcc -std=c11 -Wall -Wextra -pedantic -o hello hello.c && ./hello
```

## Переменные и печать

```c
int capacity_mah = 1500;
printf("Capacity: %d mAh\n", capacity_mah);
```

`%d` — это «дырка», в которую подставится целое число. После запятой перечисляем, чем заполнить дырки, по порядку:

```c
int a = 5;
int b = 9;
printf("%d + %d = %d\n", a, b, a + b);
```

Программа напечатает `5 + 9 = 14`.

## Ввод числа

```c
int voltage = 0;
printf("Voltage: ");
scanf("%d", &voltage);
```

В `scanf` перед именем переменной всегда ставится `&`, в `printf` — никогда.

## Было на D, стало на C

| D | C |
|---|---|
| `import std.stdio;` | `#include <stdio.h>` |
| `void main() { }` | `int main(void) { return 0; }` |
| `writeln("x = ", x);` | `printf("x = %d\n", x);` |
| `readf(" %d", &x);` | `scanf("%d", &x);` |
| `int c = a * b;` | `int c = a * b;` |

Заготовки к заданиям лежат в папке `code/` рядом с этим конспектом. Заготовка — это программа, в которой уже написано начало, а вместо пропущенных строк стоит пометка `// TODO`. Откройте её, скопируйте в редактор и допишите.

## Задание 1. Время полёта

Заготовка: [code/01_flight_time_start.c](code/01_flight_time_start.c).

Ёмкость батареи 1500 mAh, моторы потребляют 30 A. На сколько минут хватит заряда?

```

```

## Задачи

Эти две задачи для тех, кто справился с домашним заданием и хочет ещё. Заготовок для них нет — создайте новый файл и напишите программу целиком, начало можно взять из калькулятора.

Motor current (A): 30

Second battery: 2 minutes

```

Enter b: 5

17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
```

## Шпаргалка

```c
#include <stdio.h>          // печать и ввод

int x = 0;                  // целая переменная
printf("x = %d\n", x);      // печать
scanf("%d", &x);            // ввод, не забыть &
```
