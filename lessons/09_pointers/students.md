# Урок 9. Указатели

## Адрес переменной

Каждая переменная хранится в памяти в своей ячейке, и у каждой ячейки есть номер — адрес. Знак `&` перед именем переменной даёт этот адрес.

```c
int speed = 30;
printf("%p\n", (void *) &speed);
```

Напечатается что-то вроде `0x7ffd75efeadc` — у вас число будет другим, при каждом запуске оно может меняться. Именно этот `&` вы пишете в `scanf("%d", &speed)` с первого урока: `scanf` получает не саму переменную, а её адрес, поэтому и может записать в неё прочитанное число.

## Указатель

Указатель — это переменная, в которой хранится адрес другой переменной. Звёздочка в объявлении `int *p` означает «указатель на `int`», а звёздочка перед именем в выражении `*p` — «то, что лежит по этому адресу».

```c
int speed = 30;
int *speed_pointer = &speed;

printf("%d\n", *speed_pointer);
*speed_pointer = 45;
printf("%d\n", speed);
```

Первый `printf` печатает `30`, второй — `45`: запись через `*speed_pointer` изменила саму переменную `speed`, потому что указатель указывает на неё.

## Передача по адресу

Функция получает копии своих параметров, поэтому изменить переменную из `main` она не может — и вернуть через `return` может только одно значение. Если передать функции адрес, она сможет записать результат прямо в переменную вызывающего, и таких результатов может быть сколько угодно.

```c
void square_and_cube(int n, int *square, int *cube)
{
    *square = n * n;
    *cube = n * n * n;
}

int square = 0;
int cube = 0;
square_and_cube(3, &square, &cube);
printf("%d %d\n", square, cube);
```

Напечатается `9 27`. Правило запоминается парой: в вызове пишем `&square` («вот адрес, пиши сюда»), в функции пишем `*square = ...` («записать по адресу»). Массив в функцию всегда передаётся так: как адрес первого элемента, поэтому функция может изменять элементы массива.

## Шпаргалка

```c
int rpm = 1200;
int *rpm_pointer = &rpm;        // & даёт адрес, int * хранит его
printf("%d\n", *rpm_pointer);   // * читает значение по адресу
*rpm_pointer = 1500;            // * записывает по адресу: rpm стал 1500
void reset(int *value)          // функция получает адрес
{ *value = 0; }
reset(&rpm);                    // вызов с &: rpm стал 0
```
